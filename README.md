# 🔥 OSINT Intelligence Gathering System v5.0

Sistema OSINT para recolectar y analizar información pública de personas.

---

## 🧠 ¿Qué hace?

Permite buscar información usando:

- 📧 Email  
- 📱 Teléfono  
- 👤 Nombre o perfil  

Y devuelve datos como:

- Emails relacionados  
- Teléfonos  
- Redes sociales  
- Ubicación  
- Posibles filtraciones (brechas)  

---

## ⚙️ Cómo funciona

- Usa fuentes públicas (Google, GitHub, LinkedIn, HIBP)
- Relaciona datos entre sí
- Evalúa qué tan confiable es cada resultado
- Guarda todo en formato JSON
